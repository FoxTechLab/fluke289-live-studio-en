# Changelog

## 1.8.0 — 2026-10-25

- English interface, connection/storage/memory errors, tooltips, reports, CLI, offline manuals, packaging descriptions and test output.
- English documentation filenames and run.sh source launcher.
- Retains earlier measurement formats and read-only hardware behaviour.
- Reuses the window/taskbar icon and package metadata work from 1.7.1.
- Historical physical acceptance belongs to the Polish release; visual acceptance of English windows remains outstanding.

## 1.7.1 — 2026-10-25

- Custom root/child-window icon and taskbar desktop-class association.
- AppStream metadata, PNG/SVG package icons and expanded author/project descriptions. Local DEB installer presentation remains frontend-dependent.

## 1.7.0 — 2026-10-25

- Persistent measurement library, search/source filters/sort/labels/two-file comparison.
- CSV/SQLite/JSON comparison with automatic PRIMARY selection, meter or relative time, B offset and matching tolerance.
- Full-common-period pair statistics, equality at common resolution, mean/max difference, time distances and worst-pair navigation; vector PDF/CSV export protects sources.
- Timed recording with countdown while LIVE continues after completion.
- Elapsed time and point navigation with selected-sample table updates.
- Bar-graph scale refinements and separate quantity/value/range labels, including voltage under frequency PRIMARY.
- Memory destination selection before download, persistent controls and return-to-LIVE hint.
- Recording fields use individual meter timestamps.
- Explicit communication gaps in new CSV and SQLite export, legacy long-gap heuristics.
- 96 automated tests and selected V1.41 user acceptance, not calibration.

## Earlier releases

- 1.6: experimental memory listing/download/full JSON backups, binary-map research and validation limits.
- Earlier development introduced live measurement decoding, CSV/SQLite storage, formatting preservation, responsive Cairo charts, A/B markers, MIN MAX, protocol-driven lightning indication and offline About/license documentation.
